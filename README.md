# Paradisi — демонстрация материалов курса

Этот пакет содержит **страницу учебного пространства**, а не страницу продажи курса: фотофон, шесть карточек модулей, все шесть оригинальных PDF, перелистывание, прогресс и конспект. Конфиги, база данных, авторизация, личные данные пользователей и остальные страницы сайта в пакет не включены. Рабочий сайт MAMP не изменён.

## Публикация через GitHub Pages

1. Создайте отдельный репозиторий.
2. Загрузите **содержимое этой папки** в корень репозитория: `index.html`, два CSS, `course-room.js`, `course-atmosphere.png` и папку `course-materials` с PDF.
3. В настройках репозитория выберите **Pages → Deploy from a branch → main → / (root)**.
4. Передайте клиенту адрес, который покажет GitHub Pages.

**Внимание:** GitHub Pages не защищает эти материалы входом. При публикации в публичном репозитории исходные PDF доступны любому посетителю и для скачивания. `noindex` просит поисковые системы не индексировать страницу, но не ограничивает доступ. Для закрытого показа нужен другой способ публикации с авторизацией.

Это самостоятельная демонстрационная копия. Прогресс и конспект сохраняются только в браузере посетителя, не в базе данных. Для просмотра PDF требуется интернет: библиотека PDF.js загружается с CDN. Открывайте страницу через GitHub Pages или локальный веб-сервер, а не двойным нажатием на `index.html`.
